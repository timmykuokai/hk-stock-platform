# 港股篩選與分析平台（HK Stock Screener & Analytics）

針對**香港股市**設計的選股與分析平台：整合即時與歷史行情，提供熱門度／成交量、殖利率、波動度、基本面等多維度篩選，內建評分模型、視覺化儀表板、自訂策略回測、警報通知與投資組合追蹤。採模組化架構、兩層快取與資料驗證機制。

> 畫面慣例：**紅漲綠跌**（港台市場），幣別 HKD。

---

## 1. 快速開始

```bash
cd hk-stock-platform
npm install
npm start                 # http://localhost:8787
```

其他指令：

```bash
npm run smoke             # 端對端 API 冒煙測試（53 項）
npm run check-ui          # 無頭 DOM 前端渲染驗證（23 項）
npm run enrich-names      # 補齊熱門池中文名稱對照
```

首次啟動會自動在背景建立「熱門池」快照（約 120 檔大型股），之後即可直接篩選。

### 快取策略

| 資料 | TTL | 降級行為 |
|------|-----|----------|
| 即時報價 | 1 分鐘 | 失敗時回傳最後一筆可用快取並標記 `stale` |
| 日 K 線 | 30 分鐘 | 同上 |
| 基本面 | 12 小時 | 同上 |
| 證券名單 | 7 天 | 同上 |
| 池快照 | 手動／自動更新 | 標記 `fresh`／`ageMinutes` |

快取為兩層（記憶體 + `server/data/.cache`），過期先回舊值並背景刷新；來源失敗時自動降級，不會因為單一來源抖動而中斷服務。

### 資料驗證

- **K 線清洗**：剔除不完整／重複日期資料；修正未涵蓋開收盤的高低價；單日變動 >60% 僅標記不刪除（可能是除權／合股）。
- **基本面驗證**：以合理性區間過濾（殖利率 0–50%、ROE ±500%、本益比 ±5000 等），超出者視為缺值並記錄 issue。
- **單位統一**：百分比字串轉小數、金額「億／萬」字串轉絕對數值後才進入模型。
- **評分缺值**：缺資料維度不計分，權重重分配，並揭露覆蓋率（coverage）。
- **回測前視偏誤防護**：所有排名指標只用再平衡日「當下可見」的資料計算。
- **股息合理性標記**：殖利率 >12%、單次派息 >股價 8%、僅一年配息紀錄者會產生 `dividendNotes` 提醒（保留原值不刪除，避免一次性特別股息被誤讀為常態）。
- **基本面 schema 版本**：`marketData.js` 的 `FUND_SCHEMA` 遞增會讓舊快取自然失效，避免 provider 擴欄位後吃到缺欄位的舊物件。

## 4. 評分模型

七個維度各自做**百分位排名**（0–100，方向已校正），再依策略權重加總為 0–100 總分：

| 維度 | 內含指標（方向） |
|------|------------------|
| 流動性／熱門度 | 20 日均成交額↑、20 日均量↑ |
| 殖利率與配息 | 近 12 月殖利率↑、配息年數↑ |
| 估值 | 本益比↓、股價淨值比↓ |
| 基本面品質 | ROE↑、淨利率↑ |
| 風險控制 | 年化波動度↓、一年最大回撤↑（回撤越小越好） |
| 動能 | 三月報酬↑、六月報酬↑、站上年線↑ |
| 報酬穩定度 | 夏普值↑、月度勝率↑、日勝率↑ |

權重預設：**均衡型／穩健收息／成長動能／低波動防禦／價值型**，可於介面即時切換，也可在 `server/engine/score.js` 新增。

## 5. 港股十大要素評分模型

移植自原 Python 版 `analyse_hk_10_factors`，每項獨立打分 0–10，合計 100 分，並輸出可讀的觀察重點（signals）而非單一黑箱數字：

| # | 要素 | 主要輸入 |
|---|------|----------|
| 1 | 行業前景與政策環境 | 產業別、營收／盈餘成長、成長／防守／景氣循環分類 |
| 2 | 公司商業模式 | 毛利率、營業利益率、淨利率（護城河代理變數） |
| 3 | 財務健康程度 | 負債權益比、流動／速動比率、現金與負債 |
| 4 | 盈利能力與質素 | ROE、ROA、淨利率 |
| 5 | 現金流 | 營運現金流、自由現金流、FCF 殖利率 |
| 6 | 估值是否合理 | 本益比、預估本益比、EV/EBITDA、PEG、PS |
| 7 | 管理層與股東結構 | 內部人／大股東持股、機構持股 |
| 8 | 股息政策 | 殖利率、派息率、五年平均股息率、配息年數 |
| 9 | 技術面與市場行為 | 均線排列、RSI、ADX、量能比、52 週相對位置 |
| 10 | 風險因素與最壞情境 | ATR 佔股價、Beta、年化波動度、最大回撤、距 52 週低點 |

**四層決策框架**（自上而下，避免只看單一指標就下結論）：
1. 產業與政策 → 2. 基本面與財務 → 3. 估值與回報 → 4. 風險與進場時機

---

## 6. 綜合決策引擎（verdict）

把三個維度加權成一個總分與結論：

- **技術面 40%**：由十大技術訊號加權（RSI、MFI、均線排列、MACD、ADX、KD、CCI、威廉指標、量能、布林位置），正負貢獻可逐項檢視。
- **基本面 40%**：十大要素總分（排除技術面與風險項後正規化）。
- **風險 20%**：風險分數愈高代表愈穩健；由波動度、Beta、回撤、ATR、負債、流動性組成，輸出風險等級。

同時輸出：**信心指數**（關鍵欄位齊全度 0–7）、支撐／壓力、進場參考區間、參考止蝕、兩段目標價、**風險回報比**（以進場區間中值為基準）、建議關注期（依 ADX 強弱）、多空因素清單。

> 全部為量化模型的觀察結果，用語為「偏多／偏空／中性觀望／條件偏好」，不產生買賣指令。

| 投資組合 | 成本／市値／損益／當日損益／相對恒指超額、持股明細與編輯、個股集中度 |
| 警報通知 | 12 種規則類型（價格突破、單日漲跌、殖利率、波動、成交額、評分、RSI、跌破均線、回撤…）、手動或排程觸發、觸發紀錄 |
| 系統設定 | 資料源健康檢測、快取統計與清除、池快照管理、自選清單、驗證機制說明 |

## 9. 使用情境範例

**收息族**：選股器 → 快速策略「高息穩健」→ 條件為日均成交額 ≥ 2,000 萬、殖利率 ≥ 4%、一年波動度 ≤ 35%、配息 ≥ 3 年 → 切換評分策略「穩健收息」。

**動能輪動回測**：策略回測 → 排名「60 日動能」、Top 10、每月再平衡、最小成交額 5,000 萬、成本 15bps → 觀察淨值曲線與最大回撤是否優於恒指。

**持股監控**：投資組合新增部位 → 警報通知建立「跌破 50 日均線」「單日漲跌 > 5%」→ 手動或排程呼叫 `/api/alerts/check`。

**每日盤後掃描**：異動掃描 → 切「量能爆發」＋「逼近 52 週高」→ 交叉「技術訊號快篩」的 MACD 金叉 → 候選丟進多股比較，用十大要素與價位表縮圈。

**單股深度研判**：個股詳情 → 先看「綜合決策摘要」的總分與結論 → 往下看十大要素哪一項拉低分數 → 對照技術面十大訊號的正負貢獻 → 再看進場區間／止蝕／目標價與風險回報比是否合理。

## 10. 已知限制

- 基本面仰賴 Yahoo 報價頁解析（非官方 API），欄位可能隨版面調整而缺值；缺值會顯示為「—」且不參與評分，不會臆測。
- 部分冷門標的在 Yahoo 香港站無中文名稱，會退回英文名稱。
- 十大要素中的「管理層與股東結構」僅能以持股結構代理，無法評估經營者誠信與治理事件，模型會附帶「宜另行查核股權攤薄、關連交易與高層異動」提醒。
- 部分港股（尤其 H 股、雙櫃台）在 Yahoo 的內部人／機構持股可能缺值，該項會落在中性分。
- 回測未含股息再投入與稅費；成交成本以固定 bps 近似。
- 異動掃描的「量能比、距 52 週高」需要池快照重建後才有值；新增指標後請於「系統設定」重新整理池。
- 全主板（約 2,000 檔）首次建立快照需較長時間，建議於「系統設定」背景更新。
